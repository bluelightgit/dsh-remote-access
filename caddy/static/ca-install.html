安装局域网 CA 证书

本机（dsh）使用本地 CA 签名的 HTTPS 证书。把 CA 证书安装进设备的信任区后， 浏览器将不再提示“不安全”，并且 IP 变化、证书续期都不需要重新安装。

下载证书 (ca.crt)

Windows

下载文件 → 右键 → 安装证书 → 选择“本地计算机” → 下一台 → 选“将所有证书都放入下列存储” → 浏览 → “受信任的根证书颁发机构” → 完成。

macOS

双击 ca.crt → 钥匙串选“系统” → 点该证书 → “信任”展开设为“始终信任” → 输入密码确认。

iPhone / iPad

用 Safari 打开本页顶部的「下载证书」链接 (https://<本机地址>:3081/ca.crt)下载 → 设置 → 通用 → VPN 与设备管理 → 安装描述文件 → 再进入 设置 → 通用 → 关于本机 → 证书信任设置 → 打开本证书的完全信任开关。

Android

设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书 → 选择下载的 ca.crt。（部分 Android 浏览器信任用户 CA 后仍有提示，可改用 Firefox/Edge，或在 Chrome 中访问网站并手动接受一次。）

Linux

以 root 运行：
sudo cp ca.crt /usr/local/share/ca-certificates/dsh-lan-ca.crt && sudo update-ca-certificates
Firefox 需另到 设置 → 隐私与安全 → 证书 → 查看证书 → 证书颁发机构 → 导入。

安装后回到 dsh 页面刷新一次，顶部的黄色提示条会自动消失（检测到证书已信任）。若一直不消失，可能是服务器端 mDNS（avahi-daemon）未开启，提示条会退化为“始终显示并引导安装”。
